# Security Policy

PharmaShield VeriFAERS operates in a regulated domain (pharmacovigilance).
Even though it is decision-support tooling and not a clinical or regulatory
device (see `NOTICE`), we take security seriously.

## Supported Versions

This project is in active early development. Security fixes are applied to
the `main` branch. There are no long-term-supported release branches at this
time.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

**Please do NOT open a public GitHub Issue for security vulnerabilities.**

Instead, report privately via one of:

1. **GitHub Private Vulnerability Reporting** (preferred):
   Go to the repository's **Security** tab → **Report a vulnerability**.
2. **Email:** open an Issue asking for a private contact channel, or use the
   contact listed on the maintainer's GitHub profile.

When reporting, please include (as much as you can):

- A clear description of the issue and its potential impact.
- Steps to reproduce, or a minimal proof-of-concept.
- Affected versions / commits.
- Any suggested mitigation, if known.

## What to expect

- **Acknowledgement:** within 5 business days of your report.
- **Initial assessment:** within 10 business days, including severity and a
  preliminary remediation plan.
- **Coordinated disclosure:** we will agree with you on a disclosure timeline.
  Standard target is 90 days from report to public disclosure, sooner for
  severe issues, longer where infrastructure or downstream coordination is
  required.
- **Credit:** with your permission, we will credit you in the release notes
  and any associated advisory.
